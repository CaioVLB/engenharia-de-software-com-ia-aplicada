Quer explorar os resultados do experimento?

Abra o console do navegador (F12) antes de recarregar a página para visualizar a análise dos datasets, as métricas de avaliação, os erros de classificação e a matriz de confusão. Se um objeto ou array aparecer recolhido, clique na seta ao lado para expandir os detalhes.
