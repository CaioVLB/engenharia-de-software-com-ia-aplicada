# Engenharia de Software com IA Aplicada

Portfólio dos projetos práticos desenvolvidos ao longo da minha pós-graduação em **Engenharia de Software com IA Aplicada**, pela UNIPDS (grupo Cogna/Anhanguera).

## Sobre a pós

Uma pós-graduação voltada para **desenvolvedores**, com foco em aplicar IA na prática do dia a dia — RAG, agentes autônomos, arquitetura de LLMs e integração com sistemas reais — em vez de se aprofundar em matemática e estatística avançada. Carga horária total de **360h**, com professores como Erick Wendel (Google Developer Expert, Node.js Core Team), Alvaro Camillo e Ahirton Lopes (GDEs), entre outros especialistas de mercado.

## Stack principal

`JavaScript` `TypeScript` `Node.js` `Angular` `TensorFlow.js` `Neo4j` `PostgreSQL` `LLMs (OpenAI, Anthropic, Gemini)` `RAG` `Embeddings` `Vector Databases` `MCP (Model Context Protocol)` `LangChain` `LangGraph` `Kubernetes` `Terraform`

## Destaques

- **[Primeira rede neural do zero](./disciplina-01-fundamentos-ia-llms/primeira-rede-neural/)** — classificador construído com TensorFlow.js que prevê a categoria de um usuário (Premium/Medium/Basic) a partir de idade, cor preferida e localização, cobrindo o pipeline completo: normalização e one-hot encoding dos dados, rede densa com ativação ReLU, camada de saída com softmax, otimizador Adam e treinamento com categorical crossentropy.
